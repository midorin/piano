# ピアノスケール指使い表（Beta）

ブラウザ上でメジャースケールの運指を視覚的に確認しながら練習できるインタラクティブアプリです。  
**Tone.js サンプラー**によるリアルなピアノ音を搭載。  
88 鍵フル鍵盤に対応し、右手・左手・両手ユニゾンの再生が可能。

## 🌐 デモ

👉 **[GitHub Pages で開く](https://midorin.github.io/piano/)**  
（ページ上部の「音色: 正弦波」をクリックしてから「音色: ピアノ」に切り替えると、リアルピアノ音が再生されます）

## 機能

- 🎵 **Tone.js サンプラー**を使用したピアノ音（Salamander Piano ベース）
- 🎹 **88 鍵フル鍵盤描画**（クリックで試奏可能）
- 🎶 **右手／左手／両手ユニゾン**のスケール再生
- 📊 **運指番号表示**（JSON データで差し替え可能）
- ⏱ **テンポ調整スライダー**（60〜200BPM）
- 🔄 **音色切替**（正弦波 ↔ ピアノ）
- 🧩 **外部 JSON 読込**で自由にスケール定義を追加・変更

## データ仕様

`fingering.example.json` を参考に、スケールや運指パターンを拡張可能。  
形式は以下のような構造です：

```json
{
  "C": {
    "name": "Cメジャー (ハ長調)",
    "right": {
      "ascending": [
        {"note": "C", "oct": 4, "fing": 1},
        {"note": "D", "oct": 4, "fing": 2}
      ],
      "descending": [ ... ]
    },
    "left": { ... }
  },
  "G": { ... }
```

## 使い方

1. `index.html` を Web ブラウザで開く
2. 上部の調名ボタンをクリックして、確認したい調を選択
3. 右手・左手、上行・下行の 4 つのセクションで指使いを確認

## 技術仕様

- HTML5

- Vanilla JavaScript
- Web Audio API（正弦波モード）
- SVG（鍵盤描画）
