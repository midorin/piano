# ピアノスケール指使い表

2オクターブのメジャースケール（長調）の指使いを表示するWebアプリケーションです。

## 機能

- 全12調のメジャースケールに対応
- 右手・左手の指使いを上行・下行それぞれ表示
- 視覚的にわかりやすいインターフェース
- レスポンシブデザイン対応

## 対応する調

- Cメジャー (ハ長調)
- Gメジャー (ト長調)
- Dメジャー (ニ長調)
- Aメジャー (イ長調)
- Eメジャー (ホ長調)
- Bメジャー (ロ長調)
- F♯メジャー (嬰ヘ長調)
- C♯メジャー (嬰ハ長調)
- Fメジャー (ヘ長調)
- B♭メジャー (変ロ長調)
- E♭メジャー (変ホ長調)
- A♭メジャー (変イ長調)

## 使い方

1. `index.html` をWebブラウザで開く
2. 上部の調名ボタンをクリックして、確認したい調を選択
3. 右手・左手、上行・下行の4つのセクションで指使いを確認

## 表示内容

各音符に対して以下の情報が表示されます：

- **音名**: C, D, E, F, G, A, B (シャープ・フラット含む)
- **指番号**: 1(親指), 2(人差し指), 3(中指), 4(薬指), 5(小指)
- **オクターブ**: 第1〜第3オクターブ

## 技術仕様

- HTML5
- CSS3
- Vanilla JavaScript
- 外部ライブラリ不要
- オフラインで動作
